This beginner-friendly workshop introduces the basics of machine learning and how simple AI models work. Participants will explore how a small ML system can be trained to recognize faces or other basic patterns. The session covers key ideas like datasets, training, and how computers learn from examples. In collaboration with FutureBound. Check out their interactive calendar and other workshops for more learning opportunities: [https://www.concordia.ca/students/success/futurebound.html](https://www.concordia.ca/students/success/futurebound.html) 

No programming experience required!

Please make sure you have Python 3.14 and the latest version of PyTorch installed on your laptop, and bring it with you.
