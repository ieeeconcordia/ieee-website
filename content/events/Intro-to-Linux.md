## About the Event

Want to get started with Linux?
Join us for a hands-on workshop where you’ll learn the basics of the Linux operating system and command line. We’ll cover Linux setup, file navigation, essential commands, text editing with vi, and core concepts used in engineering and tech. 

Perfect for students interested in software, systems, or anyone curious about Linux. No prior Linux experience required! 

Requirements:
• Laptop with a Linux virtual machine
• VirtualBox recommended (other VM software is fine)
